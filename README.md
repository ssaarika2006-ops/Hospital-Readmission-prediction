# Hospital Readmission Prediction using Scikit-learn

This educational project predicts whether a patient may be readmitted based on synthetic patient and hospital features.

## Run
1. Install dependencies:
   pip install -r requirements.txt
2. Train the model:
   python train_model.py
3. Make a sample prediction:
   python predict.py

Important: The dataset is synthetic and this project is for learning only. It must not be used for real clinical decisions.
